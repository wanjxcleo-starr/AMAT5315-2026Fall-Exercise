# Repository context

This public repository holds the weekly AMAT5315 (Modern Scientific Computing) exercises of a graduate student taking the course. Exercises are organized in `week1/`, `week2/`, and so on.

The coursework practices agent-assisted scientific computing, testing, Git and GitHub, Python and Rust programming, mathematical modeling, and reproducible research workflows. The repository documents a reproducible and auditable learning process through specifications, tests, numerical evidence, and an ordered Git history.

Memory probe: W1-MEMORY-5315

# Instructions for Codex

- Work only within the week or files requested. Leave unrelated weeks unchanged.
- Read and follow the relevant learning sheet, specification, and design files before editing.
- Test every change with the relevant tests or verification commands. Show the results and discuss uncertainties before committing.
- Make small, focused commits with clear messages that preserve the order of the work. Do not push without the student's confirmation.
- Keep passwords, access keys, identity numbers, private notes, and other secrets out of this public repository.
- Do not commit `__pycache__/`, build outputs, or large raw data under `runs/` or `artifacts/`. A learning sheet may explicitly require a specific evidence file from those locations.
- Use `AGENTS.md` for Codex guidance. Do not create `CLAUDE.md`.
